# 🛒 Supermarket Inventory Management System (Java GUI)

A Desktop application built with Java to manage products, customers, suppliers, and categories.

### 📦 Inventory & Supermarket Management System

> A comprehensive desktop application built in **Java (GUI)**, utilizing robust Object-Oriented Programming (**OOP**) principles and **Text File I/O** for efficient data persistence in supermarkets and pharmacies.

---

## 📌 Project Overview
The **Inventory Management System (IMS)** is a multi-role solution designed to automate store operations. Built with core Java concepts, it leverages OOP structures and local text-file storage (`.txt`) to manage real-time inventory, generate detailed financial and product reports, handle client purchase orders, and issue automated email notifications.

## ✨ System Modules & Features

### 🛒 1. Product Module
* **Product CRUD:** Full Create, Read, Update, Delete capabilities for product records.
* **Smart Alerts:** Automated notifications for low stock levels and products near expiration.
* **Advanced Filtering:** Search items by name, category, or production/expiration dates.

### 🛡 2. Admin Module
* **Entities Management:** Complete control over product categories and supplier databases.
* **Financial Analytics:** Generate statistical reports, category-wise data, and total profit reports.
* **Promotional Tools:** Design and manage time-bound special discount offers for products.

### 👤 3. Client Module
* **Accounts & Orders:** User registration, profile updates, purchase request processing, and invoice generation.
* **Notifications:** Automated email confirmations for every purchase order placed.

---

## 🏗️ Architecture & Technical Highlights

* **Pure Java OOP:** Architected using fundamental OOP concepts (Encapsulation, Inheritance, Polymorphism) to represent all system entities (Products, Users, Admin, Clients, Orders).
* **Text File Persistence:** A lightweight, dependency-free storage solution where all application data is stored, read, and updated directly from local Text Files (`.txt`).
* 
# 🛠️ Tech Stack

* **Programming Language:** Java (OOP Architecture)
* **Storage:** File I/O (Text Files `.txt`)
* **User Interface:** Java GUI (Swing / JavaFX)
* **IDE:** NetBeans / Eclipse / IntelliJ IDEA
